# Проект: Оно тебе надо

## Описание проекта
"Оно тебе надо" - это лендинг для аукциона необычных вещей, в которые никто не верил. 
Проект создан для отработки навыков семантической верстки, позиционирования элементов и работы с Flexbox и CSS Grid.

## Технологии
* HTML5 (семантическая разметка)
* CSS (Flexbox, Grid)
* Pixel-perfect верстка по макету из Figma
